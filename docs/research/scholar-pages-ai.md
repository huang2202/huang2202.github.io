# AI、机器人与视觉学者网站调研

查阅日期：2026-10-07。样本根据与 AI、机器人、视觉及 embodied learning 的研究相关性，以及领域影响力选取；这不是学者排名，也不据此比较学术水平。来源限于学者本人维护的学术页、所在机构人员档案和其明确链接的实验室官网。Levine 与 Finn 的个人主页，以及 RAIL 与 IRIS 实验室首页，另有 1440×1100 本机 Chrome 截图；其余页面仅按可抽取文本核查。因此只有上述四页的具体视觉层级基于渲染截图，其他页面的栏目顺序不代表实际折叠线，本文也不从文字猜测配色和布局。

**查阅日期：2026-10-07。** [Sergey Levine 个人学术主页](https://people.eecs.berkeley.edu/~svlevine/)和[Berkeley EECS 人员档案](https://www2.eecs.berkeley.edu/Faculty/Homepages/svlevine.html)是两种不同页面。个人主页截图中，首屏先以大幅肖像和姓名、职务、地址、招生联系说明建立身份；随后是一段关于让自主智能体通过学习获得复杂行为的研究陈述，再以 RAIL 实验室标题和 Publications、Lab Members、Getting Involved 等链接引导深入阅读。下方嵌有一场标注为 2021 年的强化学习演讲。页面的人情线索主要是肖像与面向 prospective students 的联系说明。可查看[个人主页截图](screenshots/2026-10-07/levine.png)。Berkeley 人员档案则从姓名/职衔、联系信息和个人主页/论文/学位论文链接进入简介、研究领域/中心、课程、精选出版物和荣誉；研究表述覆盖决策与控制中的机器学习、深度 RL、感知与控制联合策略，以及机器人、车辆、视觉和图形。档案精选了 2025–2026 年的两条出版物，并列出一门视觉语言动作与通用机器人学习课程。 [来源：个人学术主页](https://people.eecs.berkeley.edu/~svlevine/)、[Berkeley EECS 人员档案](https://www2.eecs.berkeley.edu/Faculty/Homepages/svlevine.html)

[RAIL 实验室首页](https://rail.eecs.berkeley.edu/)又是独立入口：截图显示顶部 Home、People、Publications、Software、Contact 导航，主体以大幅团队合照和一段研究定位为主；页脚显示版权年份 2017，首页截图没有新闻流。版权年份不能单独证明页面内容过期，但提示维护者可以额外标示最近更新。可查看[RAIL 首页截图](screenshots/2026-10-07/rail.png)。

## 跨样本观察与可借鉴做法

这些页面没有单一模板：机构档案擅长快速核验职务、联系方式、研究领域和机构隶属；个人学术页更能用自己的话说明研究方向、放置 CV/课程/联系说明；实验室页则适合持续维护成员、项目、论文和代码。Levine 的 Berkeley 档案将身份、研究和教学压在同一条信息路径；Finn 的个人页把新闻与成员信息交给实验室；Li 的 Stanford 档案和 SVL 项目页分别承担个人简介和项目展示；Abbeel 与 Jordan 的论文页承担长期文献归档。以上是页面结构观察，不是设计质量排名。

对早期 embodied AI / RL 研究者，以下是基于样本的**建议**，不是样本页面已实现的统一事实：

1. 首页先用一句研究问题说明“研究什么、靠什么方法、落在哪类环境或能力”，再用一行身份/机构信息建立可信入口。Levine、Finn 的简介都把学习与决策/交互连到机器人任务；建议避免只写宽泛的“AI/机器学习”。
2. 选少数代表项目作为首页入口，每个项目给出问题、实验设置、关键结果和可验证产物。相关样本已把论文与 Project Page、Code、数据/基准测试链接分开；早期研究者可从“论文 + 项目页/视频 + 代码或数据”开始，不必等到论文数量很大。
3. 把精选成果和完整论文档案分层：精选区服务第一次访问者，按年份的长目录服务同行查找。项目页应直接回到论文，论文也应能找到代码、演示或数据集，形成闭环。Chelsea 的 IRIS 和 Abbeel 的个人目录可作链接颗粒度参考。
4. 单独维护研究方向、项目、论文、成员/招生、教学和联系方式的入口。若新闻更新不稳定，可像 Finn 的个人主页那样清楚指向一个持续维护的渠道；若在首页发布新闻，给日期和简短标题，避免把长期论文档案误作近期动态。
5. 个人元素保持真实且轻量，例如一段研究动机、简短背景或一张可访问的照片。Abbeel 的简历页放有访谈与图片入口，Jordan 的主页连接团队照片；它们补足人的线索，但不取代研究材料。
6. 保持“谁在做研究”与“研究本身”的页面边界，同时明确相互链接。校方档案可能由机构维护，个人站也可能迁移；主页应标明最近更新，并把机构档案和实验室站连到同一个当前入口。访问核查时要区分浏览器渲染和文本抓取结果：Levine 个人主页在本机 Chrome 可正常渲染，但文本抓取工具返回 404，因此不能把单一工具错误当作站点失效。
