# Triage Labels

The engineering skills use five canonical triage roles. This file maps each role to the label used in this repo's GitHub Issues.

| Canonical role    | GitHub label      | Meaning                                  |
| ----------------- | ----------------- | ---------------------------------------- |
| `needs-triage`     | `needs-triage`     | Maintainer needs to evaluate this issue   |
| `needs-info`       | `needs-info`       | Waiting on reporter for more information |
| `ready-for-agent`  | `ready-for-agent`  | Fully specified, ready for an agent       |
| `ready-for-human`  | `ready-for-human`  | Requires human implementation            |
| `wontfix`          | `wontfix`          | Will not be actioned                     |

When a skill mentions a role, use the corresponding GitHub label from this table.

Edit the GitHub label column if the repo adopts a different label vocabulary.
